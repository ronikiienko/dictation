The encoder runs on the GPU, while the decoder stays on the CPU because it is small and mostly sequential. Most of the time goes into matrix multiplication, so we wrote our own kernels for Metal instead of relying on the default ones. The weights are stored as eight bit integers with a scale for each block of thirty two values. On long recordings, the audio is cut into pieces at natural pauses, and each piece is transcribed separately. The kernel cache keeps compiled shaders on disk, so the second run starts much faster than the first. Memory usage stays below one gigabyte, which matters on a laptop with only eight gigabytes of shared memory.
